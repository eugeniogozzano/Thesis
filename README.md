
# Forecasting Olympic Medal Counts: Interpretability vs. Accuracy
**Master of Science Thesis Repository — Statistics & Data Science (Leiden University)**

This repository contains the complete computational workflow, data orchestration pipeline, and statistical modeling for forecasting Olympic medal counts. 

The core methodological objective of this research is to bridge structural socio-economic modeling with non-linear machine learning architectures. The pipeline benchmarks structural parametric models (Generalized Linear Mixed Models, `glmmTMB`) against complex tree-based ensembles. By integrating **Explainable AI ** frameworks, specifically **TreeSHAP** (SHapley Additive exPlanations), the workflow extracts marginal feature contributions, unpacking non-linear socio-economic and demographic interactions without sacrificing predictive accuracy.

## 🔄Automated Data Pipeline & Orchestration

The data ingestion workflow employs a hybrid architecture, combining local static files with dynamic API calls to maximize auditability:

*   **Dynamic API Fetching:** Historical Olympic records, Human Development Index (HDI) metrics, Gender Development Index (GDI), and World Bank Population totals are pulled dynamically via automated REST API queries and R packages (`WDI`, `jsonlite`, GitHub raw content) at runtime.
*   **ISO Standard Harmonization:** Country identifiers are rigorously mapped to the ISO 3166-1 alpha-3 standard (`countrycode`). Dissolved macroeconomic entities and non-sovereign regional codes (e.g., URS, GDR, World Bank aggregates) are algorithmically purged to maintain a consistent longitudinal panel.
*   **Structural Missingness & Feature Engineering:** The pipeline calculates rolling athletic prime-age demographics (15-39), handles lagged performance metrics, dynamically accounts for host-nation advantages, and longitudinally interpolates missing economic data points using `zoo::na.approx`.
*   **Contextual Imputation (2024 Sanctions):** Automatically handles structural zeros generated by geopolitical sanctions (e.g., RUS/BLR athletes competing as AIN in Paris 2024) to prevent distortion of long-term socio-economic capacity metrics.
